This repository contains the DFT calculation data supporting the manuscript entitled “Unveiling the Roles of Defect Species in Photocatalysis and Adsorption on the Anatase TiO2 Surface,” submitted under manuscript ID ANSN-2026-0863.

- The folder defects_on_surface_PBE stores PBE-level DFT calculations for the formation energy of the surface defects.
- The folder defects_in_bulk_PBE stores PBE-level DFT calculations for the formation energy of the bulk defects.
- The folder defect_states_DDH stores DDH-level DFT calculations for the defect state energies of the surface defects. This is done only for the most energetic stable surface defects. 
- The folder MB_on_defects_surface_PBE+vdw stores PBE+vdw-level DFT calculations for the binding energy of the MB molecules on the most energetic stable surface defects.
